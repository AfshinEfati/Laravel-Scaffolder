# Quick Start

The core command of this package is `make:module`. It generates a full stack for a specific feature.

## Prerequisite

Typically, you should have an existing Eloquent model or a migration file.

```bash
php artisan make:model Product -m
```

## Basic Usage

Generate a basic module for the `Product` model:

```bash
php artisan make:module Product
```

## API Stack

Generate an explicit API stack (Controller, Requests, Actions):

```bash
php artisan make:module Product --api
```

## Full Stack

To generate everything (Repository, Service, DTO, Policy, Resources, Tests, Swagger):

```bash
php artisan make:module Product --all
```

## Overwriting Existing Files

If you want to re-generate and overwrite existing files:

```bash
php artisan make:module Product --all --force
```
