# API Response Helper

The published `App\Helpers\ApiResponseHelper` provides a consistent way to return JSON responses from your controllers.

## Standard Responses

```php
use App\Helpers\ApiResponseHelper;

// 200 OK
return ApiResponseHelper::successResponse($data, 'Message');

// 201 Created
return ApiResponseHelper::successResponse($product, 'Product created', 201);

// 404 Not Found
return ApiResponseHelper::notFound('User not found');

// 403 Forbidden
return ApiResponseHelper::forbidden();

// 401 Unauthorized
return ApiResponseHelper::unauthorized();

// 422 Validation Error
return ApiResponseHelper::errorResponse('Validation failed', 422, $errors);
```

## Data Transformation

The helper also includes methods for formatting data:

### Dates
```php
ApiResponseHelper::formatDates(now());
// Returns: ['date' => '2024-03-20', 'fa_date' => '۱۴۰۳/۰۱/۰۱', ...]
```

### Status Labels
```php
ApiResponseHelper::getStatus(true);
// Returns: ['name' => 'active', 'fa_name' => 'فعال', 'code' => 1]
```
