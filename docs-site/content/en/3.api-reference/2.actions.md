# Action API

Generated CRUD actions are invokable classes that encapsulate a single business operation. They include built-in logging and error handling.

## Overview

When you generate a module with actions, you get a set of classes in `app/Actions/{Module}/`:
- `Create{Module}Action`
- `Update{Module}Action`
- `Delete{Module}Action`
- `List{Module}Action`

## Usage in Controller

You can type-hint the action in your controller method and invoke it directly.

```php
use App\Actions\Product\CreateProductAction;
use App\DTOs\ProductDTO;

public function store(Request $request, CreateProductAction $createProduct)
{
    // The action is invokable
    $product = $createProduct(ProductDTO::fromRequest($request));

    return response()->json($product, 201);
}
```

## Logging

All actions use the configured log channel. If an exception occurs, it is logged before being rethrown. You can configure the channel in your `.env`:

```env
MODULE_GENERATOR_LOG_CHANNEL=stack
```

## Manual Execution

You can also call the `execute()` method explicitly:

```php
$action->execute($data);
```
