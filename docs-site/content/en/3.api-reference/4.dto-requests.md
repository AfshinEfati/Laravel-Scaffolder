# DTO and Form Requests

The package automates the process of data validation and transfer between the HTTP layer and your business logic.

## Form Requests

Generated form requests in `app/Http/Requests/` contain validation rules inferred from your model's schema or the `--fields` option.

- `Store{Module}Request.php`
- `Update{Module}Request.php`

## Data Transfer Objects (DTO)

DTOs provide a type-safe way to pass data. They use PHP 8 readonly properties.

```php
namespace App\DTOs;

class ProductDTO
{
    public function __construct(
        public readonly string $name,
        public readonly ?float $price,
        public readonly bool $is_active,
    ) {}

    public static function fromRequest(Request $request): self
    {
        return new self(
            name: $request->validated('name'),
            price: $request->validated('price'),
            is_active: $request->validated('is_active', true),
        );
    }
}
```

### Usage
```php
$dto = ProductDTO::fromRequest($request);
echo $dto->name;
$array = $dto->toArray(); // Automatically filters null values
```
