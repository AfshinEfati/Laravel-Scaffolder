# Schema and Fields

The generator intelligently merges metadata from multiple sources to understand your model's structure.

## Metadata Sources

1. **Inline Fields**: Defined using the `--fields` option.
2. **Migrations**: Extracted from files using `--from-migration`.
3. **Runtime Metadata**: Inspected from existing database columns and Eloquent model attributes.

## Field Syntax

Fields are defined as: `name:type:modifier1:modifier2`

```bash
--fields="name:string:unique,price:decimal(10,2):nullable,category_id:integer:fk=categories.id"
```

## Supported Types

- `string`, `text`, `longText`
- `integer`, `bigInteger`, `foreignId`
- `decimal`, `float`, `boolean`
- `date`, `datetime`, `timestamp`
- `json`, `uuid`, `email`, `url`

## Modifiers

- `nullable`, `optional`
- `unique`
- `fk=table.column`: Defines a foreign key relationship.
- `required`: (Default) ensures the field is validated as required.

## Example Usage

```bash
php artisan make:module Subscription --api \
  --fields="plan:string,status:string,expires_at:datetime:nullable"
```
