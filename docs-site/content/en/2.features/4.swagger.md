# Swagger and OpenAPI

Generating API documentation is a breeze with Laravel Scaffolder. It provides a standalone workflow to generate and serve Swagger UI.

## Initialization

First, initialize the Swagger UI assets:

```bash
php artisan swagger:init
```

## Generating Specification

Generate the `swagger.json` file based on your Laravel routes:

```bash
php artisan swagger:generate
```

## Serving the UI

You can serve the documentation using the built-in server:

```bash
php artisan swagger:ui
```
Then visit `http://localhost:8000` to see your API documentation.

## Module Documentation

When generating a module, you can add PHPDoc annotations automatically:

```bash
php artisan make:module Product --api --swagger
```

## Configuration

You can customize the Swagger UI (theme, colors, title) using the config command:

```bash
php artisan swagger:config --theme=dark --primary-color=#8b5cf6
```
Alternatively, edit the environment variables in your `.env` file (e.g., `SWAGGER_THEME`, `SWAGGER_COLOR_PRIMARY`).
