# Jalali Dates

The package provides a powerful and lightweight wrapper around Carbon for handling Jalali (Persian) dates, using the `Goli` class.

## Basic Usage

You can use the `Goli` class or the `goli()` helper function.

```php
use Efati\ModuleGenerator\Support\Goli;

// Get current date
$date = Goli::now();
echo $date->toGoliDateString(); // Output: 1403/01/01

// Format with Persian digits
echo $date->format('Y/m/d', true); 

// Difference for humans in Persian
echo $date->subDays(5)->diffForHumans(); // Output: ۵ روز پیش
```

## Eloquent Integration

To automatically handle Jalali dates in your models, use the `GoliDateCast` or the `HasGoliDates` trait.

### Using Casts

```php
use Efati\ModuleGenerator\Casts\GoliDateCast;

protected function casts(): array
{
    return [
        'published_at' => GoliDateCast::class,
    ];
}
```

### Using Trait

```php
use Efati\ModuleGenerator\Support\HasGoliDates;

class Post extends Model
{
    use HasGoliDates;

    protected array $goliDates = ['published_at', 'expires_at'];
}
```

## Parsing Dates

```php
$parsed = Goli::parseGoli('1403/01/01 08:30:00');
$carbon = $parsed->toCarbon(); // Convert to standard Carbon instance
```
