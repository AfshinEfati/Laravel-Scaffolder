# هلپر پاسخ‌های API

کلاس `App\Helpers\ApiResponseHelper` که پس از نصب منتشر می‌شود، روشی یکسان برای بازگرداندن پاسخ‌های JSON در کنترلرها ارائه می‌دهد.

## پاسخ‌های استاندارد

```php
use App\Helpers\ApiResponseHelper;

// پاسخ موفقیت (200 OK)
return ApiResponseHelper::successResponse($data, 'پیام موفقیت');

// ایجاد شده (201 Created)
return ApiResponseHelper::successResponse($product, 'محصول ایجاد شد', 201);

// پیدا نشد (404 Not Found)
return ApiResponseHelper::notFound('کاربر یافت نشد');

// دسترسی غیرمجاز (403 Forbidden)
return ApiResponseHelper::forbidden();

// خطای اعتبارسنجی (422 Validation Error)
return ApiResponseHelper::errorResponse('خطا در داده‌ها', 422, $errors);
```

## تبدیل داده‌ها

این هلپر متدهایی برای فرمت‌دهی داده‌ها نیز دارد:

### تاریخ‌ها
```php
ApiResponseHelper::formatDates(now());
// خروجی: ['date' => '2024-03-20', 'fa_date' => '۱۴۰۳/۰۱/۰۱', ...]
```

### وضعیت‌ها (Status)
```php
ApiResponseHelper::getStatus(true);
// خروجی: ['name' => 'active', 'fa_name' => 'فعال', 'code' => 1]
```
