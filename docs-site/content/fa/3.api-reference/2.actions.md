# لایه Action

اکشن‌های CRUD تولید شده کلاس‌های قابل فراخوانی (invokable) هستند که یک عملیات تجاری واحد را کپسوله می‌کنند. این کلاس‌ها دارای قابلیت ثبت لاگ و مدیریت خطای داخلی هستند.

## نمای کلی

هنگامی که ماژولی را با اکشن‌ها تولید می‌کنید، مجموعه‌ای از کلاس‌ها در مسیر `app/Actions/{Module}/` ایجاد می‌شوند:
- `Create{Module}Action`
- `Update{Module}Action`
- `Delete{Module}Action`
- `List{Module}Action`

## استفاده در کنترلر

می‌توانید اکشن را در متد کنترلر خود تزریق (Type-hint) کرده و مستقیماً آن را فراخوانی کنید.

```php
use App\Actions\Product\CreateProductAction;
use App\DTOs\ProductDTO;

public function store(Request $request, CreateProductAction $createProduct)
{
    // اکشن به صورت invokable قابل استفاده است
    $product = $createProduct(ProductDTO::fromRequest($request));

    return response()->json($product, 201);
}
```

## ثبت لاگ (Logging)

تمام اکشن‌ها از کانال لاگ تنظیم شده استفاده می‌کنند. در صورت بروز خطا، ابتدا لاگ ثبت شده و سپس خطا دوباره پرتاب (rethrow) می‌شود. تنظیم کانال در `.env`:

```env
MODULE_GENERATOR_LOG_CHANNEL=stack
```

## اجرای دستی

همچنین می‌توانید متد `execute()` را به صورت صریح صدا بزنید:

```php
$action->execute($data);
```
