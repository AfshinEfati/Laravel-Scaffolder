# لایه DTO و Request

این پکیج فرآیند اعتبارسنجی و انتقال داده بین لایه HTTP و منطق برنامه را خودکار می‌کند.

## کلاس‌های Form Request

کلاس‌های تولید شده در `app/Http/Requests/` شامل قوانین اعتبارسنجی هستند که از روی ساختار مدل یا گزینه `--fields` استخراج شده‌اند.

- `Store{Module}Request.php`
- `Update{Module}Request.php`

## کلاس‌های DTO (Data Transfer Object)

کلاس‌های DTO روشی امن (Type-safe) برای انتقال داده‌ها فراهم می‌کنند.

```php
namespace App\DTOs;

class ProductDTO
{
    public function __construct(
        public readonly string $name,
        public readonly ?float $price,
        public readonly bool $is_active,
    ) {}

    public static function fromRequest(Request $request): self
    {
        return new self(
            name: $request->validated('name'),
            price: $request->validated('price'),
            is_active: $request->validated('is_active', true),
        );
    }
}
```

### نحوه استفاده
```php
$dto = ProductDTO::fromRequest($request);
echo $dto->name;
$array = $dto->toArray(); // مقادیر نال را به صورت خودکار حذف می‌کند
```
