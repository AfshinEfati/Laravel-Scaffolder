# شروع سریع

فرمان اصلی این پکیج `make:module` است که تمام لایه‌های مورد نیاز برای یک قابلیت را تولید می‌کند.

## پیش‌نیاز

معمولاً باید یک مدل Eloquent یا فایل Migration از قبل داشته باشید.

```bash
php artisan make:model Product -m
```

## استفاده معمولی

تولید ماژول پایه برای مدل `Product`:

```bash
php artisan make:module Product
```

## ساختار API

تولید ساختار کامل API شامل Controller و Actionها:

```bash
php artisan make:module Product --api
```

## تولید تمام لایه‌ها

برای تولید همه لایه‌ها شامل Repository، Service، DTO، Policy، Resource، Test و Swagger:

```bash
php artisan make:module Product --all
```
