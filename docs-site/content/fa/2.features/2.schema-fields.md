# تعریف فیلدها و اسکیما

ژنراتور پکیج به صورت هوشمند اطلاعات فیلدها را از منابع مختلف جمع‌آوری و ترکیب می‌کند.

## منابع اطلاعاتی

۱. **فیلدهای دستی**: تعریف شده با گزینه `--fields`.
۲. **فایل Migration**: استخراج شده با گزینه `--from-migration`.
۳. **دیتابیس**: بررسی خودکار ستون‌های جدول در دیتابیس (اگر جدول وجود داشته باشد).

## ساختار تعریف فیلد

فیلدها به این صورت تعریف می‌شوند: `نام:نوع:ویژگی۱:ویژگی۲`

```bash
--fields="name:string:unique,price:decimal(10,2):nullable,category_id:integer:fk=categories.id"
```

## انواع داده پشتیبانی شده

- `string`, `text`, `longText`
- `integer`, `bigInteger`, `foreignId`
- `decimal`, `float`, `boolean`
- `date`, `datetime`, `timestamp`
- `json`, `uuid`, `email`, `url`

## ویژگی‌ها (Modifiers)

- `nullable`, `optional`: فیلد می‌تواند خالی باشد.
- `unique`: مقدار فیلد باید یکتا باشد.
- `fk=table.column`: تعریف کلید خارجی و رابطه با جدول دیگر.

## مثال کاربردی

```bash
php artisan make:module Subscription --api \
  --fields="plan:string,status:string,expires_at:datetime:nullable"
```
