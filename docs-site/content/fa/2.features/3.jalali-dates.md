# تاریخ جلالی

این پکیج شامل کلاس `Goli` است که یک پوشش قدرتمند و سبک بر روی Carbon برای مدیریت تاریخ‌های هجری شمسی (جلالی) فراهم می‌کند.

## استفاده پایه

می‌توانید از کلاس `Goli` یا هلپر `goli()` استفاده کنید.

```php
use Efati\ModuleGenerator\Support\Goli;

// دریافت تاریخ فعلی
$date = Goli::now();
echo $date->toGoliDateString(); // خروجی: 1403/01/01

// فرمت‌دهی با اعداد فارسی
echo $date->format('Y/m/d', true); 

// نمایش اختلاف زمان به فارسی
echo $date->subDays(5)->diffForHumans(); // خروجی: ۵ روز پیش
```

## استفاده در مدل‌های Eloquent

برای اینکه تاریخ‌های مدل شما به صورت خودکار به شمسی تبدیل شوند، از `GoliDateCast` یا تریت `HasGoliDates` استفاده کنید.

### استفاده از Cast

```php
use Efati\ModuleGenerator\Casts\GoliDateCast;

protected function casts(): array
{
    return [
        'published_at' => GoliDateCast::class,
    ];
}
```

### استفاده از Trait

```php
use Efati\ModuleGenerator\Support\HasGoliDates;

class Post extends Model
{
    use HasGoliDates;

    protected array $goliDates = ['published_at', 'expires_at'];
}
```

## تبدیل و پارس کردن

```php
$parsed = Goli::parseGoli('1403/01/01 08:30:00');
$carbon = $parsed->toCarbon(); // تبدیل به نمونه استاندارد Carbon برای ذخیره در دیتابیس
```
