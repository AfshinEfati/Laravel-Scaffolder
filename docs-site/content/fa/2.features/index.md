# فرمان تولید ماژول

فرمان `make:module` ابزار اصلی برای تولید خودکار لایه‌های پروژه است.

```text
php artisan make:module {name} [options]
```

## گزینه‌ها

| گزینه | نام کوتاه | کاربرد |
| --- | --- | --- |
| `--api` | — | تولید Controller نوع API و فعال‌سازی خودکار Request و Action. |
| `--all` | `-a` | تولید تمام لایه‌های ممکن (Repository، Service و ...). |
| `--fields=...` | — | تعریف مستقیم فیلدها در فرمان. |
| `--from-migration=...` | `-fm` | خواندن اطلاعات فیلدها از یک فایل Migration. |
| `--force` | — | بازنویسی فایل‌های موجود در صورت وجود. |

## مثال‌های کاربردی

### ۱. تولید ماژول API ساده
تولید ماژول متمرکز بر API همراه با اعتبارسنجی و اکشن‌ها:
```bash
php artisan make:module Order --api
```

### ۲. تولید تمام لایه‌ها با فیلدهای دستی
اگر مدلی ندارید، می‌توانید فیلدها را مستقیم تعریف کنید:
```bash
php artisan make:module Product --all \
  --fields="name:string,price:decimal(10,2),is_active:boolean"
```

### ۳. فقط تولید مستندات
اگر می‌خواهید فقط فایل Swagger مربوط به یک ماژول را تولید یا بروزرسانی کنید:
```bash
php artisan make:module Product --swagger
```

## فایل‌های تولید شده
در صورت استفاده از گزینه `--all` فایل‌های زیر به پروژه اضافه شوند:
- **Repository**: لایه دسترسی به دیتابیس
- **Service**: لایه منطق تجاری برنامه
- **DTO**: انتقال داده‌های معتبر بین لایه‌ها
- **Actions**: کلاس‌های مستقل برای هر عملیات CRUD
- **Resource**: تبدیل خروجی برای API
- **Test**: تست‌های Feature برای صحت عملکرد عملیات
