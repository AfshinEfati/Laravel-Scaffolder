# مستندات Swagger و OpenAPI

تولید مستندات API با این پکیج بسیار ساده است. شما یک جریان کاری کامل برای تولید فایل OpenAPI و نمایش آن در Swagger UI دارید.

## آماده‌سازی

ابتدا دارایی‌های مورد نیاز برای رابط کاربری را ایجاد کنید:

```bash
php artisan swagger:init
```

## تولید فایل مشخصات (Specification)

فایل `swagger.json` را بر اساس روت‌های تعریف شده در لاراول تولید کنید:

```bash
php artisan swagger:generate
```

## نمایش مستندات

می‌توانید مستندات را با استفاده از سرور داخلی پکیج مشاهده کنید:

```bash
php artisan swagger:ui
```
سپس آدرس `http://localhost:8000` را در مرورگر باز کنید.

## مستندات مخصوص ماژول

هنگام تولید یک ماژول، می‌توانید از گزینه `--swagger` استفاده کنید تا کدهای PHPDoc مربوطه به صورت خودکار تولید شوند:

```bash
php artisan make:module Product --api --swagger
```

## تنظیمات ظاهری

می‌توانید ظاهر Swagger UI را (تم، رنگ‌ها، عنوان) با فرمان مخصوص تغییر دهید:

```bash
php artisan swagger:config --theme=dark --primary-color=#8b5cf6
```
همچنین می‌توانید از متغیرهای محیطی در فایل `.env` (مانند `SWAGGER_THEME`) استفاده کنید.
